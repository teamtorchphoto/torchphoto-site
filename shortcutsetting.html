TorchPhoto Backup

Shortcut Version 2

This shortcut backs up items captured today to the server locations you choose in TorchPhoto.

Add TorchPhoto Backup

How the backup works

  1. 1
    Photos are uploaded first

    The shortcut finds photos captured today and uploads them to the selected destination.

  2. 2
    Live Photo motion clips are uploaded as MOV files

    Live Photos are detected next, and their motion clips are exported and uploaded as short MOV files.

  3. 3
    Videos are uploaded as MOV files

    Videos captured today are detected last, converted to MOV when needed, and uploaded to the selected video destination.

Automatic thumbnails: TorchPhoto generates thumbnails automatically during each shortcut upload.

Choose three backup locations

When you add or run the shortcut for the first time, choose each destination from the servers and folders already added in TorchPhoto.

  1. 1
    Photo backup location

    Select the server and folder where regular photos captured today should be uploaded.

  2. 2
    Live Photo backup location

    Select where Live Photo MOV clips should be uploaded. In most cases, choose the same folder as the photo backup location so matching photo and MOV files stay together.

  3. 3
    Video backup location

    Select the server and folder where videos captured today should be uploaded.

Only new items are uploaded

Duplicate protection: Items that have already been uploaded are skipped automatically instead of being overwritten. Each run checks the same backup flow again, but uploads only new items that are not already on the server.

Completion notification: When the shortcut finishes, a Shortcuts notification displays the combined total number of uploaded photos and videos.

Automation trigger tips

  • Assign the backup shortcut to the Action Button on supported iPhone models to start a photo backup instantly.
  • Create a Personal Automation that runs the backup whenever the Camera app is closed.
  • Run the backup automatically at a specific time each day, such as every evening.
  • Start a backup when the iPhone is connected to a charger.
  • Run the backup when the device connects to a specific Wi-Fi network, such as your home network.
  • Use an arrival trigger to start a backup when you reach home or another selected location.
  • Place the shortcut on the Home Screen, Lock Screen, Back Tap, or an NFC tag for quick manual access.

Get ready in TorchPhoto

  1. 1
    Add your server

    Use TorchPhoto PRO and save an FTP, SFTP, SMB, or WebDAV connection. Check that your device can reach the server.

  2. 2
    Check your Upload options

    Open the Upload page and choose your media options, including Live Photo video upload and JPEG conversion. Both shortcuts use your saved upload options.

  3. 3
    Allow photo access

    For today’s automatic backup, allow photo-library access in TorchPhoto first. Limited access uploads only the items you have allowed.

Add a shortcut and choose its destination

  1. 1
    Choose one of the two shortcuts

    Use the buttons above, or open Settings → Set Up Shortcut in TorchPhoto. Choose either backup in the popup to open its iCloud import link.

  2. 2
    Select Server and Folder

    During setup, choose a saved TorchPhoto server and the folder to upload to. Each shortcut uses one destination. To change it later, edit the shortcut in the Shortcuts app.

  3. 3
    Run it once and check the result

    Today’s shortcut finds the current day’s photos and videos automatically. The selected-items shortcut opens the photo picker and uploads your selection without a date filter.

Upload history: Check Upload Logs on the Upload page for the result. Thumbnail generation follows your saved Upload option. If a run is interrupted, open the Upload page to check whether it offers a saved upload to resume.

Looking for this guide again? The Upload page’s Shortcuts suggestion opens this website and then stays hidden. Settings → Reset Tips restores it. The logo page’s Shortcuts link also opens the website guide.

Make today’s backup automatic

Create a Personal Automation in the Shortcuts app and have it run the shortcut for today’s items. Its start and end dates both use the current date, so there is no date to update each day.

  • Run at a chosen time, such as each evening.
  • Run when your device connects to a charger.
  • Choose a trigger that fits when your server is reachable, such as connecting to your home Wi-Fi.

Selected-items shortcut: You still need to choose items in the photo picker whenever it runs. Use it for uploads you start yourself.

Automatic execution depends on the trigger and iOS permissions. Test the shortcut on your network before relying on it for regular backups.

Live Photos and more help

Today’s shortcut uses TorchPhoto’s date-based photo-library upload, including the Live Photo components enabled in your Upload options. The selected-items shortcut uploads the files that Shortcuts supplies.

Plans

Free vs Pro

See the key differences at a glance and choose the experience that fits your workflow.

FREE

FREE

Offers trial-level features.

  • Thumbnail cache up to 200MB (auto-deletes when exceeded)
  • Only video files under 50MB are supported for thumbnail generation
  • Server Live Photos appear as one photo and one video.
  • No server slideshow
  • Thumbnail sharing with a 30-minute cooldown
  • You can upload up to 50 items at a time
  • Optimization features are not supported
PRO

PRO

Supports all features for a smoother, more flexible workflow.

  • Unlimited thumbnail cache
  • Adjustable video thumbnail skip settings
  • Server Live Photos are shown as paired photos and videos
  • FTP Server slideshow support
  • No thumbnail sharing cooldown
  • There is no limit on the number of items you can upload
  • Fast, optimized enhancements are applied

1. Choose Your Backup Shortcut

Today’s Captures or Your Own Selection

Back Up Today’s Items uses the Upload by Date action. Its start and end dates are both set to the current date, so it covers today’s photos and videos each time it runs.

Back Up Selected Items opens the photo picker and passes your selection to Upload Files. It does not filter by capture date, and it needs you to choose items when it runs.

2. Set Up Your Server and Folder

One Destination for Each Shortcut

First, add your FTP, SFTP, SMB, or WebDAV server in TorchPhoto. Use either download button above, or open Settings → Set Up Shortcut in TorchPhoto and choose the shortcut you want from the popup.

While adding the shortcut, choose its Server and Folder. You can change them later in the Shortcuts editor. Review the options on TorchPhoto’s Upload page before running it.

To back up another period, edit the start and end dates in Upload by Date. Both days are included; set the same date for a single day. Upload Files accepts files from earlier shortcut steps without a date filter.

For date-based uploads, open TorchPhoto and allow access to your photo library first. If you grant limited access, only the items you allow can be uploaded.

3. Live Photos and Upload Options

Use Your Saved Upload Settings

The date-based shortcut uses TorchPhoto’s photo-library uploader. Live Photo video, JPEG conversion, and other media options follow the settings saved on the Upload page. Separate photo, Live Photo, and video conversion steps are not needed for this workflow.

The selected-items shortcut uploads the files supplied by Shortcuts. Media components available to it depend on what Shortcuts passes. For backups that need the original Live Photo components, use the date-based workflow with Live Photo video upload enabled.

4. Check Upload Results

Upload Logs and Recovery

Uploads use TorchPhoto’s existing duplicate-handling rules. Check the Upload Logs on the Upload page for the result of each run, including any skipped or failed items.

If an upload is interrupted, open the Upload page to check whether a saved upload can be resumed. Thumbnail generation follows your saved Upload option.

5. Set Up an Automation

In the Shortcuts app, create a Personal Automation that runs Back Up Today’s Items at your preferred time or when your device connects to a charger. Choose automatic execution if your iOS version and trigger offer that option.

Back Up Selected Items is suited to manual use, such as launching it from Shortcuts or the Action Button. Its photo picker requires your input, even if an automation starts it.

6. Before Your First Backup

Run the shortcut once while you are using the device to confirm the server, folder, photo access, and network connection. A server on your home network requires a connection to that network or a suitable VPN.

Start with a small upload and review its log before relying on a regular automation. Automatic execution remains subject to iOS permissions and background limits.

7. Where Your Files Go

Photos and videos are transferred directly from your device to the server you select in TorchPhoto. TorchPhoto does not upload them to a separate photo-storage service. The iCloud links above are used to add the shortcuts.

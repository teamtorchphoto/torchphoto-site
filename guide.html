Remote FTP/SMB Access with VPN

Use a VPN for Remote FTP Access

FTP can send login information and file data without encryption, depending on the server configuration. If you need to use FTP from outside your home or office, avoid exposing the FTP port directly to the public internet. Connect to your home or NAS network through a VPN first, then add the FTP server in TorchPhoto using its internal LAN address.

SMB is also usually best kept inside a local network. If your NAS supports SMB and your VPN allows access to devices on the home LAN, you can connect through the VPN first and then add the SMB server with its local address instead of opening SMB ports to the internet.

  • FTP remote setup: VPN + local FTP address
  • Why it helps: the VPN places your device on the local network and reduces direct exposure of plain FTP traffic
  • SMB remote setup: VPN + local SMB address, when your NAS and VPN routing support LAN access
  • Modern VPN option: WireGuard is simple, fast, and widely recommended
  • Avoid when possible: direct public FTP or SMB port forwarding for private photo storage
Instant Thumbnail Generation

How Instant Thumbnails Work

Instant thumbnail generation lets TorchPhoto create thumbnails quickly without downloading the full original file from your server. TorchPhoto reads only enough original data to build a preview, so large folders can be prepared faster and with less waiting.

You can choose Low or High for instant thumbnail generation. Low prioritizes speed and is the best choice when you want thumbnails as quickly as possible, but a small number of items may fail to generate. High is slower than Low, but it can slightly improve the success rate for files that need more data to create a thumbnail.

If an instant thumbnail still fails, you can generate it later with TorchPhoto's high-quality thumbnail improvement feature. Thumbnail improvement creates standard high-quality TorchPhoto thumbnails without the instant-thumbnail limitations, so failed instant thumbnails can still be completed reliably.

  • Low: fastest instant thumbnail generation, with a chance that some thumbnails may fail
  • High: slower than Low, but can slightly increase thumbnail generation success
  • Recommended flow: start with instant thumbnails, then use thumbnail improvement for failed items or thumbnails that need better detail
1. Add a Server

How to Add a Server

Open the add server screen in the app, then enter the address, port, username, and password before saving.

  • Enter the server address and port
  • Enter login information
  • Save and test the connection
2. QR Code Share

QR Code Sharing and Scanning

You can easily share and import server connection details with a QR code. This is useful when quickly registering the same server on multiple devices.

  • Long-press a server item and select Share QR
  • Scan instantly with the camera on another device
  • Share the QR image and scan it
3. Generate Thumbnails

Generate Thumbnails

Generate thumbnails in the desired server folder to browse photos and videos quickly in a gallery-style layout.

  • Move to a folder containing photos or videos
  • Run thumbnail generation
  • Supports server-wide thumbnail generation
4. Share Thumbnails

Share Thumbnails

Share generated thumbnails to quickly send sample images. This is useful when reviewing only the needed scenes first. Unlimited thumbnail sharing is available in PRO.

  • Long-press a server item and select Share Thumbnails
  • Create a single zip file
  • Share while keeping the folder path structure
5. Folder Tag

Folder Tag Feature

Tap the folder name to assign tags. Enter multiple tags separated by commas.

  • Tap the folder name to assign tags
  • Use commas for multiple tags
  • Search tags on the server list screen
6. Upload / Backup

Upload and Backup

Back up photos and videos to a server you add with FTP, SFTP, SMB, or WebDAV. Long-press the server icon to automatically select items from a specified period.

  • Select photos and videos to upload
  • Choose the server folder
  • Use automatic date-based selection
7. Play Slideshow

Play Slideshow

You can automatically play photos in the selected folder. This is ideal for browsing memories stored on the server like an album. This feature is available in PRO.

  • Long-press a server item to start the slideshow
  • Adjust playback interval
  • Play by server unit
8. Offline Mode

Offline Mode

Use pre-generated thumbnails to keep browsing even without internet or with an unstable connection. This is especially useful while on the move.

  • Use cached thumbnails
  • Works well on unstable networks
  • Browse while preserving the server folder structure
9. Thumbnails Widget

Thumbnail Widget

Use generated server photo thumbnails as widgets on the home screen. Thumbnail widgets also work without internet access.

  • Generate thumbnails, then go to the settings screen
  • Select a folder in widget settings at the bottom
  • Use thumbnails based on server photos
10. Save Video Frame

Save Video Frame

Save a desired moment from a video as an image. It is saved while preserving the original resolution.

This feature works the same way in the paired video (Live Photo) viewer as well. When you long-press the paired video, Live Photo frames appear at the bottom, and you can save them using the same frame save button.

  • Play a video from the server
  • Long-press the video to view metadata
  • Save a frame from the bottom section of the metadata view
11. Quick Start

Quick Start

Quick Start is a PRO-only feature that skips the logo screen at launch and takes you directly to the server list screen for faster access.

  • Open Settings in TorchPhoto
  • Enable the Quick Start feature
  • Launch the app and go straight to the server list screen
12. Thumbnail Cache Backup & Restore

Thumbnail Cache Backup & Restore

Thumbnail Cache Backup & Restore is a PRO-only feature that lets you back up generated thumbnail cache and restore it later without generating thumbnails again. It is especially useful when using the same server across multiple iOS devices, since you can quickly apply your existing thumbnail cache through backup and sharing instead of repeating the thumbnail generation process on each device. This helps you save time and access your gallery-style thumbnail view much faster after setting up TorchPhoto on another device or restoring your data.

  • Open Settings in TorchPhoto
  • Go to Thumbnail Cache Backup & Restore
  • Back up your generated thumbnail cache or restore a saved backup when needed
13. Live Photo Pairing

Live Photo Pairing

This feature makes a Live Photo uploaded to the server as one video file and one photo file appear like a Live Photo in the default iOS Photos app. This feature is available in PRO.

  • Turn on the Video Pairing feature in Settings
  • The photo and video will be shown as a single Live Photo
  • A short video will play from the icon in the top-left corner of the photo viewer
14. Save Live Photo

Save Live Photo

You can save a paired Live Photo to the iOS Photos app. In other words, one video file and one photo file are saved together as a single Live Photo. This feature is available in PRO.

  • Turn on the Video Pairing feature in Settings
  • Play the Live Photo video for the photo you want to save
  • Long-press the Live Photo and tap the Save Live Photo button at the bottom
15. Wi-Fi Gallery Share

Wi-Fi Gallery Share

Wi-Fi Gallery Share lets other devices on the same Wi-Fi network view your TorchPhoto server gallery through a web browser. Open the shared address or scan the QR code to browse photos and videos from Chrome, Safari, or other browsers.

  • Easy access with address or QR
  • Works in a web browser
  • Local Wi-Fi network only

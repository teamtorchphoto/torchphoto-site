Guide

Tap an item below to expand the guide with images and instructions.

1. Add a Server

How to Add a Server

Open the add server screen in the app, then enter the address, port, username, and password before saving.

  • Enter the server address and port
  • Enter login information
  • Save and test the connection
2. QR Code Share

QR Code Sharing and Scanning

You can easily share and import server connection details with a QR code. This is useful when quickly registering the same server on multiple devices.

  • Long-press a server item and select Share QR
  • Scan instantly with the camera on another device
  • Share the QR image and scan it
3. Generate Thumbnails

Generate Thumbnails

Generate thumbnails in the desired server folder to browse photos and videos quickly in a gallery-style layout.

  • Move to a folder containing photos or videos
  • Run thumbnail generation
  • Supports list mode or grid mode
4. Share Thumbnails

Share Thumbnails

Share generated thumbnails to quickly send sample images. This is useful when reviewing only the needed scenes first.

  • Long-press a server item and select Share Thumbnails
  • Create a single zip file
  • Share while keeping the folder path structure
5. Folder Tag

Folder Tag Feature

In the viewer screen, long-pressing an item selects one item first, and holding longer selects all items. Tap the folder name to assign tags, separated by commas.

  • Tap the folder name to assign tags
  • Use commas for multiple tags
  • Search tags on the server list screen
6. Upload / Backup

Upload and Backup

Back up photos and videos to an FTP server. Long-press the server icon to automatically select items from a specified period.

  • Select photos and videos to upload
  • Choose the server folder
  • Use automatic date-based selection
7. Play Slideshow

Play Slideshow

You can automatically play photos in the selected folder. This is ideal for browsing memories stored on the server like an album.

  • Long-press a server item to start the slideshow
  • Adjust playback interval
  • Play by server unit
8. Offline Mode

Offline Mode

Use pre-generated thumbnails to keep browsing even without internet or with an unstable connection. This is especially useful while on the move.

  • Use cached thumbnails
  • Works well on unstable networks
  • Browse while preserving the server folder structure
9. Thumbnails Widget

Thumbnail Widget

Use generated server photo thumbnails as widgets on the home screen. Thumbnail widgets also work without internet access.

  • Generate thumbnails, then go to the settings screen
  • Select a folder in widget settings at the bottom
  • Use thumbnails based on server photos
10. Save Video Frame

Save Video Frame

Save a desired moment from a video as an image. It is saved while preserving the original resolution.

  • Play a video from the server
  • Long-press the video to view metadata
  • Save a frame from the bottom section of the metadata view

Q&A

Frequently asked questions about TorchPhoto.

Where can I ask new questions or get in touch?

Please email us at teamtorchphoto@gmail.com, and we will review it and reply as soon as possible.

What kind of app is TorchPhoto?

TorchPhoto is an iOS app designed to help you browse photos and videos stored on servers you add with FTP, SFTP, SMB, or WebDAV, including NAS devices and personal servers. It focuses more on photo and video viewing than a typical file explorer.

What can I do with TorchPhoto alone?

TorchPhoto can work as a server-based viewer for photos and videos captured on iPhone or iPad, and it also lets you upload selected items to the directory you want on your server. With Shortcuts, you can build automatic upload flows using triggers that match your own routine. TorchPhoto also remembers generated thumbnails and directory paths, so you can review your server library in an offline-friendly way after thumbnails have been prepared. Some features are supported more completely in PRO.

Which server connection methods does TorchPhoto support?

When you add a server in TorchPhoto, you can choose FTP, SFTP, SMB, or WebDAV as the connection method. Pick the method that matches your NAS or personal server, then browse, upload, and manage your photo and video library through that server connection.

What is the best way to share a TorchPhoto Gallery viewer?

Use the Wi-Fi Gallery Share feature. Long-press the server you want to share from the server list, then share the gallery. On any device, you can open it in a web browser such as Safari or Chrome and enjoy an efficient gallery viewer that loads thumbnails first, then switches to the original image. Thumbnails are generated on the iOS device, and the original files are downloaded and displayed naturally. If Video Pairing is enabled in TorchPhoto settings, this feature can also provide a Live Photo-like experience even in web browsers on devices that do not support Live Photos.

Can I change the port for the Local Wi-Fi Gallery URL?

Yes. In the Local Wi-Fi Gallery feature, tap the displayed URL to edit the port. This is useful if the default port is already in use or if you want to set a different port for your local sharing environment.

What file extensions are supported?

Supports formats natively recognized by the iOS Photos app, photos and videos captured with the camera, and a wide range of specialized image and video file extensions.

How is it different from a typical file transfer app?

While a typical file transfer app focuses on file management, TorchPhoto focuses more on media browsing with features like photo and video viewing, thumbnail generation, offline thumbnail browsing, QR sharing, metadata viewing, and slideshow.

The app is very small in size. Can I trust it?

TorchPhoto is optimized to stay lightweight and efficient, helping save storage space on your iOS device. The app itself is kept as small as possible, and it also includes an app data cleanup feature to reduce unnecessary storage usage. Although TorchPhoto has a relatively small app size compared to the number of features it offers, its features are designed to work together smoothly and reliably.

Does TorchPhoto send diagnostic data automatically?

No. TorchPhoto includes an on-device diagnostic feature to support app operation, updates, optimization, stability, and feature improvements. TorchPhoto does not automatically upload its locally stored diagnostic file. It remains on your device unless you choose to export and send it, such as through a feedback email. If a diagnostic notice appears in Settings, please use Send Error whenever possible so the technical context can help reproduce and improve the problem. Apple’s separate system analytics may still follow your device analytics settings and Apple’s privacy terms.

Can user-generated thumbnail cache be deleted automatically?

User-generated thumbnails are now stored locally on the iOS device as app data instead of temporary cache files. This prevents TorchPhoto thumbnails from being automatically removed by iOS storage cleanup. When launching the latest version, TorchPhoto will automatically migrate existing thumbnail data from the previous cache location to the new app data location. You can still use the Backup & Restore feature in Settings to move or recover thumbnail data when needed.

Why can Database Optimization appear on the server list?

After updating to the latest version, TorchPhoto may migrate existing local index data to a more efficient database format when you open the server list. This one-time optimization helps the app find thumbnail and timeline information more efficiently. After the migration completes successfully, it does not run again. If the app closes before completion, TorchPhoto can safely continue the remaining work the next time you open the server list. The process affects only TorchPhoto's local app data and does not modify original files on your server.

Is it a cloud storage service?

No. TorchPhoto is not a separate cloud storage service. It connects directly to servers you add with FTP, SFTP, SMB, or WebDAV, so you can view photos and videos stored on your own storage.

Can I use it with NAS?

Yes. If your NAS supports FTP, SFTP, SMB, or WebDAV access, choose that method when adding the server in TorchPhoto. It works well with NAS devices such as Synology and QNAP that can enable one of these connection methods.

Can I view photos and videos together?

Yes. Photos and videos in the same folder can be displayed together, so mixed media folders can be browsed naturally like an album.

Does it support grid view and list view?

Yes. You can use both grid and list layouts while browsing folders depending on your preference.

How does TorchPhoto handle folders with many items?

If a folder contains more than 1,000 thumbnail items, TorchPhoto automatically divides the folder into page sections of 1,000 items each for smoother browsing. For example, a folder with 3,300 thumbnail items is shown across 4 pages. Tap the total item count in the header to open a page menu and jump quickly to the page you want.

Can it preview and play videos?

Yes. The app supports video preview and playback so you can immediately check clips stored on the server.

Are search, sort, and filter available?

Yes. Search and sorting are supported, making it easier to focus on photos only or videos only when needed.

Can I check EXIF and IPTC metadata?

Yes. Long-press a supported photo or video in the viewer to open its metadata. TorchPhoto can show available file information, EXIF details, location data, and embedded IPTC fields. Only information that actually exists in the media is displayed, so the available fields can differ from one file to another.

What is IPTC metadata, and is an IPTC title the same as a filename or TorchPhoto caption?

IPTC is descriptive information embedded in a media file, such as a title, headline, description, keywords, creator, credit, copyright, and location names. An IPTC title is separate from a filename such as IMG_0001.jpg, and it is also separate from TorchPhoto's own caption feature. TorchPhoto reads the IPTC information stored in the original file and does not create missing IPTC values automatically.

Can I choose which metadata fields appear and change their order?

Yes. Open the metadata view by long-pressing the media, then use the edit button beside the close button. You can show or hide individual EXIF, IPTC, file, and location fields and drag them into the order you prefer. These display preferences change only TorchPhoto's metadata view and do not edit the original file.

What is Custom Popup?

Custom Popup displays the metadata fields you select directly over supported image, video, and animated image viewers after the original media and its metadata are ready. In Settings > Custom Popup, you can choose the fields and their order, customize field titles and font sizes, set the display duration, background transparency and text shadow, and choose a fixed or manually saved position. The feature starts turned off on a new installation.

How do I move or hide Custom Popup in the viewer?

When Lock Position is off, press and hold the popup itself, then drag it to the desired position. TorchPhoto remembers the saved position. When Lock Position is on, choose Top Left or Top Right and the popup aligns itself to the displayed media. Quickly double-tap the popup to hide it. Starting to zoom the media also hides it for the current item. Normal viewer swipes remain available unless you are actively repositioning the popup.

What is Timeline Viewer?

Timeline Viewer is a thumbnail-based gallery that brings together generated thumbnails from your registered servers. It lets you browse them by Year, Month, Day, or Location without navigating each server folder separately.

How do I open Timeline Viewer?

Tap the Timeline Viewer button on the server list. A normal tap opens the timeline; a long press prepares and opens Metadata Scan instead.

Which date does Timeline Viewer use for sorting?

TorchPhoto prioritizes the capture date stored in the file metadata when it has been verified. If no usable capture date is available, it uses the file modification date. Newer items appear first within the selected Year, Month, or Day view.

How do I jump to a specific date in Timeline Viewer?

Tap the date heading at the top of Timeline Viewer. In Year view, choose a year. In Month view, choose a year and then a month. In Day view, choose a year, month, and day in order. Each step is built from dates that actually contain generated thumbnails, so the picker does not offer empty dates.

Why did an item move to a different place in the timeline?

An older thumbnail may initially be arranged by its file modification date. After thumbnail regeneration or Metadata Scan verifies its original capture date, Timeline Viewer rebuilds the relevant data and places the item at the correct capture date and time.

Why are some server items missing from Timeline Viewer?

Timeline Viewer works from generated TorchPhoto thumbnails. Generate a thumbnail for an item before expecting it to appear. Unsupported items, folders, and files without a generated thumbnail are not timeline entries.

Can I browse Timeline Viewer when a server is offline?

Generated thumbnails and the local timeline catalog allow the gallery to remain useful when the original server is unavailable. Opening, saving, or sharing a full original still requires access to that server unless the original is already available locally.

How does the Location view group photos and videos?

TorchPhoto groups nearby GPS locations according to the current map zoom. A grouped marker uses a representative thumbnail and shows the full item count. Zoom in to separate it into smaller areas; zoom out to combine nearby areas into a stable regional group.

What opens when I tap a thumbnail on the Location map?

Tapping a location marker opens a regional timeline containing the items represented by that marker. You can browse that region by Year, Month, or Day and adjust the thumbnail grid between 3 and 8 columns.

Why is an item visible by date but missing from the Location map?

The Location view requires usable GPS coordinates in the original metadata. An item without GPS can still appear in Year, Month, and Day views, but TorchPhoto cannot place it on the map.

Is the Location map fully available offline?

TorchPhoto stores the indexed coordinates and generated thumbnails locally, so known location groups can still be prepared without reconnecting to every original. The map imagery itself is supplied by Apple MapKit and depends on the map tiles currently available to iOS; a complete offline map is therefore not guaranteed.

How do I start Metadata Scan?

On the server list, long-press the Timeline Viewer button. TorchPhoto displays Metadata Scan Loading while it prepares eligible items, then opens the scan page and starts. You can use Cancel during preparation to stop before entering the scan page.

Does Metadata Scan inspect every original file on my servers?

No. It scans photo and video entries that already have generated TorchPhoto thumbnails. Originals without thumbnails are not added to the scan just because they exist on a server.

What information does Metadata Scan collect?

It looks for the original capture date and GPS coordinates when those fields exist. TorchPhoto stores the result in its local thumbnail metadata index for timeline sorting and the Location map; it does not write the result into the original server file.

Do newly generated thumbnails need a separate Metadata Scan?

Normally, no. New and regenerated thumbnails save available capture-date and location information during thumbnail generation. Metadata Scan is mainly useful for older thumbnails or items whose metadata could not previously be confirmed.

Does Metadata Scan download the complete original?

Not by default. TorchPhoto first reads a limited part of the file. Photos are normally inspected from that partial data. Videos can keep metadata in different parts of the container, so TorchPhoto may also inspect another limited section when the protocol supports it. If required video metadata still cannot be confirmed, it can temporarily download the complete video for one deeper check and remove the temporary copy afterward.

Will the same video be downloaded in full on every Metadata Scan?

No. Once a complete video inspection finishes, TorchPhoto records that the deeper check was completed—even when the original genuinely has no capture date or GPS—so it does not repeatedly download that video in full. A communication failure can remain eligible for a later retry.

Does Metadata Scan support videos as well as photos?

Yes. Both thumbnail-backed photos and videos are included. Some video containers store metadata differently, which is why a video may require a deeper inspection than a photo.

What does “Unable to Verify” mean in Metadata Scan?

It means TorchPhoto could not reliably confirm the requested metadata for that item. The original may not contain a usable date or location, its format may store the information in an unsupported way, or a read or connection problem may have interrupted verification. TorchPhoto does not invent missing metadata.

What happens when an original has no capture date or GPS?

An item without GPS is skipped only in the Location map. An item without a verified capture date remains sortable by its file modification date. The original file and its metadata remain unchanged.

Can I stop Metadata Scan safely?

Yes. Tap Stop. TorchPhoto finishes stopping the active work safely and keeps results already processed; the button then changes to Close so you can leave the page.

Why does the screen stay awake during Metadata Scan?

TorchPhoto temporarily prevents automatic screen sleep while scanning so iOS is less likely to interrupt the foreground work. Normal screen-sleep behavior returns after the work stops or the scan page closes.

Does Metadata Scan work with FTP, SFTP, SMB, and WebDAV?

Yes. The scan uses the connection path available for each registered protocol. Partial-read capabilities can differ between servers and protocols, so the internal retrieval method may vary, but the capture-date and GPS results are stored in the same local format.

What maintenance runs when Metadata Scan starts?

TorchPhoto reconciles the local metadata index with existing thumbnails, removes metadata entries whose matching thumbnails no longer exist, clears outdated timeline catalog data, and rebuilds the timeline from the current results. This keeps the metadata index and thumbnails on the same lifecycle.

Are timeline and metadata records included in Thumbnail Cache Backup & Restore?

Yes. The local metadata associated with the backed-up thumbnails is included so capture-date sorting and known GPS locations can be restored with matching thumbnail data. The backup still does not contain your full-resolution originals.

What should I do when a diagnostic item appears in Settings?

Please tap Send Error whenever possible. TorchPhoto prepares a feedback email with the diagnostic report attached. Review it, add what you were doing when the problem occurred, and send it. That context is often the fastest way to reproduce an intermittent issue and improve the app.

What happens if I choose Ignore on a diagnostic notice?

Ignore closes the notice without sending a diagnostic report. Choose it only when you do not want to share the report; Send Error is recommended because an unreported issue can be much harder to investigate.

Does tapping Send Error upload a report immediately?

No. TorchPhoto prepares a feedback email with the diagnostic attachment for you to review and send. If mail is not available on the device, TorchPhoto displays an alert instead of silently uploading anything.

How do I add, edit, or remove a caption?

Open the photo or video, display its metadata details, and use the Caption section to add or edit your note. Captions are saved after surrounding blank spaces are removed. To remove an existing caption, clear its text and save.

What is the caption popup in the media viewer?

When an item has a saved caption, TorchPhoto briefly shows it near the top of the media viewer so you can read the note without opening metadata. The popup supports up to three visible lines, and its display time automatically adjusts to the caption length, from about 2 seconds up to 6 seconds.

Does a caption change the original photo or video?

No. Captions are stored locally by TorchPhoto for the corresponding server and remote path. They are not written into the original file or its embedded metadata on your server. When you use the PRO thumbnail cache backup and restore feature, saved captions for that server are included with the backup.

Can I upload photos and videos from iPhone to the server?

Yes. You can select photos and videos and upload them to the folder you want on a server added with FTP, SFTP, SMB, or WebDAV, including multiple files at once.

Can I upload directly to the folder I am viewing?

Yes. Inside a folder, tap the menu button in the top-right corner and choose Upload. The photo selection screen opens for the current server and current folder, so the selected photos and videos can be uploaded immediately to that exact location.

Can I check upload history?

Yes. You can review successful and failed upload records in the Upload Log.

Can I download photos and videos from the server?

Yes. You can download photos and videos stored on the server to your iPhone or iPad.

Is it also available on Mac?

If the app appears in the App Store on your device, you can use the iPad-designed version and its features on Mac as well.

Can I share photos and videos directly?

Yes. It supports sharing through the iOS share sheet, and you can also share directly from the video preview screen.

What is thumbnail generation?

Generating thumbnails in advance allows faster and lighter browsing even in large folders or on slow networks. With instant thumbnail generation, TorchPhoto can create quick previews by downloading only part of the original file first, which improves speed and storage efficiency without requiring full original downloads for every thumbnail.

What is the difference between Low, High, and Ultra for instant thumbnails?

Low prioritizes speed, so thumbnails can be generated as quickly as possible, but a small number of items may fail. High reads more source data to improve the success rate. Ultra reads the most source data and may take longer, but offers the best chance for difficult files. All three produce thumbnails with the same final dimensions and storage quality.

If some items fail while using Low, try High and then Ultra. If thumbnails appear cropped or do not display correctly, turn off instant thumbnail generation and run thumbnail generation again to create TorchPhoto high-quality thumbnails. You can also keep instant thumbnail generation enabled and use the thumbnail improvement feature to replace selected instant thumbnails with high-quality thumbnails.

What should I do if thumbnails do not display correctly or look cropped?

If an instant thumbnail failed to generate, try High and then Ultra. If a generated thumbnail appears cropped or does not display correctly, turn off instant thumbnail generation and run thumbnail generation again. TorchPhoto will then create a high-quality thumbnail. You can also keep instant thumbnail generation enabled and use the thumbnail improvement feature to replace selected instant thumbnails with high-quality thumbnails.

What should I do if there is a visible shift when a thumbnail switches to the original?

Instant thumbnails are created from partial image data or the file's original embedded image information, which may not reflect later edits. As a result, the thumbnail's crop or aspect ratio can occasionally differ from the original and cause a visible shift when the full image appears. To avoid this, use Thumbnail Improvement after creating the instant thumbnail, or turn off Instant Thumbnail Generation and create a TorchPhoto high-quality thumbnail instead. Either option will generate a thumbnail that matches the original more closely.

Can folders show whether thumbnails have been generated?

Yes. Folders can be displayed as thumbnail items when thumbnails have already been generated inside them. This makes it easier to recognize folders that are ready for thumbnail-based browsing.

How does two-step thumbnail generation work?

If instant thumbnail generation is enabled, TorchPhoto first creates fast, efficient preview thumbnails from partial original data. Later, you can select the items you want and improve them into TorchPhoto's standard high-quality thumbnails. This lets both Free and PRO users save storage and data first, then upgrade only the thumbnails that need clearer detail.

What does Enhance Thumbnail Quality do?

Enhance Thumbnail Quality improves how generated thumbnails are displayed during preview. It works with Instant Low, Instant High, Instant Ultra, and TorchPhoto high-quality thumbnails, but it does not modify the original media file or overwrite the saved thumbnail cache.

This setting is independent of SDR Quality Enhancement. Its offline option applies only to thumbnail enhancement while browsing offline.

Why do instant thumbnails look low quality in widgets?

Instant thumbnails are optimized for speed and capacity savings, so they can look much lower quality in widget-style views. If you want to use specific items in widgets or slideshow-style displays, improve those selected thumbnails to TorchPhoto high-quality thumbnails first.

Can I view thumbnails offline?

Yes. Once generated and cached, thumbnails remain viewable even when there is no internet or the server is not connected.

Is it useful on unstable networks?

Yes. Since it uses thumbnail-based browsing, it is useful for quickly checking visual previews even in weak or unstable signal conditions.

Can I share thumbnails themselves?

Yes. Thumbnail Share lets you share light and fast preview images instead of originals. It is useful for sample delivery or quick selection work.

Does it support widgets and slideshows?

Yes. Generated thumbnails can be displayed in iOS widgets, and slideshow playback is supported for digital-frame style use.

Is it convenient for files split like Live Photo?

Yes. Even when photo and video files are stored separately on servers added with FTP, SFTP, SMB, or WebDAV, TorchPhoto helps you browse them more naturally together.

How can I save a Live Photo stored on the server?

In the pairing video viewer, press and hold the Live Photo video, then tap Save Live Photo at the bottom. (The pairing viewer feature is available in PRO.)

Can multiple people browse the same server?

Yes. As long as each person has access permissions, they can browse the same server library on their own device, whether the server is added with FTP, SFTP, SMB, or WebDAV.

Can I share server information with a QR code?

Yes. The Share QR feature lets you send server connection info as a QR code, so another user can register the server more easily without manual typing.

Are caches separated by server?

Yes. If the host and port combination is different, it is treated as a different server, and caches and browsing data are managed separately.

Can I delete cache for only one server?

Yes. You can delete cache per server, and you can also clear the cache for all servers at once.

Does it support both iPhone and iPad?

Yes. TorchPhoto is designed to work on both iPhone and iPad.

What is the difference between Free and PRO?

Free provides the core TorchPhoto experience, while PRO removes key limits for more comfortable browsing of larger libraries. Free can register 1 server and has up to 100MB of thumbnail cache, while PRO supports unlimited registered servers and unlimited thumbnail cache. PRO also includes video pairing, large video thumbnail generation, slideshow, and no time limit on thumbnail sharing.

How can I switch from a monthly subscription to PRO lifetime?

First, cancel your monthly subscription. While your PRO access is still active, back up all generated thumbnails using the Backup feature in Settings. After your monthly subscription ends and TorchPhoto switches back to the Free version, purchase PRO lifetime. Then restore your thumbnail backup from Settings.

What information do I need to add a server?

Select the correct protocol and enter the server address, port, username, password or supported authentication information, and root path. The values must match the settings on your FTP, SFTP, SMB, or WebDAV server.

Can I register the same server with more than one protocol?

Yes. For example, the same NAS can be registered once with SMB and again with WebDAV. TorchPhoto treats each protocol and port combination as a separate connection, so its browsing data and thumbnail cache remain separate.

Can I connect to my server from outside my home network?

Yes, if the server is already reachable from the internet or through a VPN and the selected protocol is configured correctly. TorchPhoto does not itself make a private server publicly accessible, so remote-access and firewall settings must be prepared on the server or network side.

Why does iOS ask for Local Network permission?

This permission is needed when TorchPhoto connects to a NAS, computer, or other server on the same local network. If access was denied, enable Local Network for TorchPhoto in the iOS Settings app and try again.

Are FTP and SFTP interchangeable?

No. SFTP is a different protocol that runs over SSH; it is not simply an encrypted switch for a normal FTP connection. Choose the protocol and port actually enabled by your server.

What should I check when adding a WebDAV server?

Check whether the server uses HTTP or HTTPS, confirm its port, and enter the correct WebDAV root path. A web page opening in a browser does not always mean that the same address is the WebDAV endpoint.

What should I enter as the SMB root path?

The SMB path normally starts with the share name, followed by an optional subfolder. If the root is left at the server level, TorchPhoto can show available shares first, depending on the account's permissions.

Does SMB support anonymous access?

It can, when the SMB server itself permits guest or anonymous access. If the share requires an account, enter the correct username and password instead.

Why can I connect to a server but see no files?

Check the registered root path, the account's folder permissions, and Media-Only Mode. A successful login only confirms the connection; an incorrect root, restricted account, or active media filter can still leave the folder looking empty.

What happens if the server IP address or port changes?

Edit the saved server with the new address or port. Because the server identity has changed, previously generated cache may be treated separately even if the physical storage is the same.

Why are the same files cached again after changing the protocol or port?

TorchPhoto separates cache by connection identity to prevent files from different servers from being mixed. Changing FTP to SFTP, SMB to WebDAV, or changing the port creates a separate cache context.

How are saved server passwords protected?

Server passwords and supported SFTP key information are stored using the device's secure credential storage rather than being written into the thumbnail files.

Can I organize a long server list?

Yes. Server search, color tags, ordering, and saved server management help separate personal, work, local, and remote connections.

What happens when I return to TorchPhoto after a long time in the background?

TorchPhoto checks the current network and reloads the server path when needed. A brief offline or retry state can appear while iOS restores the network connection, but cached thumbnails and folder information can remain available during that check.

Does an offline message mean my server files were deleted?

No. It means the current connection could not be used. TorchPhoto may show a saved folder snapshot and cached thumbnails until the server becomes reachable again.

What is Media-Only Mode?

Media-Only Mode shows compatible photos and videos while hiding unrelated files. If a file exists on the server but is not visible, temporarily check this setting and the current photo/video filter.

Are folders hidden when Media-Only Mode is enabled?

No. Folders remain available so you can continue navigating, while unsupported or unrelated files inside them are filtered from the media list.

Does search look through the entire server?

Directory search is intended for the currently loaded browsing context. If the file is in another folder, move to that folder or use the server's folder navigation first.

Can I show only photos or only videos?

Yes. Use the media filters to narrow the current folder to the type you want. Filters affect what is shown; they do not delete or move the hidden files.

Why does a folder show a four-image preview?

When suitable child thumbnails are available, TorchPhoto can combine them into a compact folder preview. The preview is only a visual guide and does not change the contents of the folder.

Why does a folder not have a preview image yet?

The folder may not contain supported media, its child thumbnails may not have been generated, or the server may currently be offline. Open the folder or generate thumbnails, then refresh after the required previews are available.

Can I favorite an entire folder?

No. TorchPhoto favorites are designed for individual media items with thumbnails, not whole folders.

Does adding a favorite copy the original file?

Not necessarily. A favorite is mainly a quick way to return to the selected media item. Whether the original can be opened offline still depends on whether an appropriate local copy is available; the remote original may still require the server.

How can I select many items efficiently?

Enter selection with a long press, then use drag selection where available. In large lists, the selection gestures are designed to help extend the range without opening every item individually.

What do the gestures in the image preview do?

Horizontal movement changes the media item, a downward swipe closes the preview, and an upward swipe opens sharing when the current zoom and preview state allow it. Pinch and pan are used for image enlargement and movement.

Why is horizontal swiping briefly unavailable while an image is loading?

TorchPhoto may temporarily hold horizontal navigation while the thumbnail, improved preview, or automatically loaded original is being prepared. This prevents an unfinished result from being applied to the next photo.

Can I close the image preview while the original is downloading?

Yes. Swipe down to close it normally. TorchPhoto cancels or discards work that belongs to the closed preview so the directory can remain usable.

Does pinch zoom follow the point under my fingers?

Yes. Zooming is centered around the pinch location, and movement is limited so the enlarged image does not drift unnecessarily beyond its visible bounds.

Does TorchPhoto respect Reduce Motion?

Yes. Optional visual transitions are reduced or skipped when the system's Reduce Motion setting is enabled, while the underlying browsing and loading behavior remains the same.

Are thumbnails copies of my original photos?

No. They are smaller preview images used for fast browsing. The original remains on the server unless you explicitly save, share, upload, move, or delete it through an available action.

Will clearing thumbnail cache delete files from my server?

No. Clearing cache removes TorchPhoto's generated previews, not the original server files. The thumbnails can be generated again later.

Should I generate thumbnails for one folder or the entire server?

Use current-folder generation when you need one area quickly. Use server-wide generation when you want broader offline visual browsing and have enough time, network capacity, and local cache space.

Why can thumbnail generation pause when I open a preview?

TorchPhoto gives the active preview priority and temporarily reduces competing thumbnail work. Generation can continue after the preview closes.

Does thumbnail generation always download the entire original?

Not always. TorchPhoto first tries efficient partial methods for supported images and videos. If a safe thumbnail cannot be produced that way, it can fall back to downloading more data or the full file.

Why did thumbnail generation use more data than expected?

The file may not contain a usable embedded preview, the server may not support the required partial reads, or the media format may need the complete file. In those cases, the normal full-download thumbnail path is used.

Why does a large video show a placeholder instead of a frame?

If the configured large-video thumbnail limit is reached, TorchPhoto can mark the item with a placeholder instead of downloading a very large file just to extract one frame. This is a completed skip state, not necessarily an error.

What happens to thumbnails when a server file is renamed or moved?

Thumbnail identity includes the file path. A renamed or moved item can therefore appear as a new item and may need a new thumbnail, while old cache data can later be cleaned up.

Why can an instant thumbnail have a slightly different crop from the original?

Some cameras and editing apps store an embedded preview with a different aspect ratio or crop. Instant Thumbnail can use that lightweight preview, so the final original can reveal a slightly different composition.

What should I choose between Instant Thumbnail Low, High, and Ultra?

Low prioritizes speed but may miss some files. High reads more source data to improve the success rate. Ultra reads the most source data and may take longer, but offers the best chance for difficult files. All three produce thumbnails with the same final dimensions and storage quality. If an item still fails, use Thumbnail Improvement or TorchPhoto's normal high-quality generator.

Does Enhance Thumbnail Quality overwrite the thumbnail cache?

No. The improved result is used for the current preview experience and does not replace the remote original or permanently rewrite the saved thumbnail cache.

What does SDR Quality Enhancement do?

When an SDR original is enlarged to at least about 1.5×, TorchPhoto can enhance the visible area on device. Hold the same visible area briefly while processing finishes. This does not modify the original file or overwrite the thumbnail cache.

If Enhance Thumbnail Quality is off, can zoomed originals still be improved?

Yes. SDR Quality Enhancement and Enhance Thumbnail Quality are independent settings. Turning off thumbnail enhancement does not disable visible-area enhancement for a sufficiently enlarged SDR original.

Which thumbnails can appear in the widget?

Only generated thumbnails that match the server and folder selected in widget settings are used. Large-video skip placeholders and thumbnails from unrelated folders are excluded.

Why is a photo missing from the widget?

Confirm that its thumbnail has been generated and that the correct server and folder are selected for the widget. If the media was moved, deleted, or skipped as a large video, it may no longer be eligible.

What is included in a thumbnail backup?

The backup is for generated TorchPhoto thumbnail data. It is not a backup of the original photos, videos, NAS contents, or the server itself.

When is thumbnail backup especially useful?

Use it before changing devices, reinstalling the app, or making a subscription change that could affect the available cache limit. Keep the original server identity and paths consistent for the restored previews to match correctly.

Will thumbnails survive if I delete and reinstall TorchPhoto?

Do not rely on app deletion to preserve local cache. Create a thumbnail backup first if you want to restore generated previews after reinstalling.

What happens when a thumbnail cache limit is reached?

TorchPhoto manages cached previews according to the active Free or PRO cache policy and the selected limit. Older or less-needed previews may be removed, but the original server files are not affected.

Can the original load automatically after the thumbnail?

Yes. Original auto-loading can replace the preview after the full image is ready. The Wi-Fi and cellular options let you control when this network-heavy step is allowed.

Why does the thumbnail remain visible instead of the original?

The server may be offline, original auto-loading may be disabled for the current network, or the download may have failed. The thumbnail can still be viewed because it is stored separately on the device.

Can I prevent large original downloads over cellular data?

Yes. Keep automatic original loading restricted to Wi-Fi and do not enable cellular original auto-load. You can still browse cached thumbnails and decide when to request an original.

Are originals available offline just because thumbnails are cached?

No. A cached thumbnail is only a preview. Opening, saving, or sharing the full-quality original still requires the server unless a local copy has already been saved through another supported action.

What is TimeMapStamp?

TimeMapStamp is the preview information card that can show the media's capture time and available location details. Optional Sunrise & Sunset and Moon Phase information can be added beneath it.

How do I hide or show TimeMapStamp in the viewer?

When TimeMapStamp is visible, briefly tap its information card or mini map to hide it. When it is hidden, tap the lower area of the screen to show it again. It stays in the state you choose while you swipe between photos and videos and no longer disappears automatically. Closing the viewer and opening it again starts with TimeMapStamp visible when the feature is enabled and usable information is available.

Can TimeMapStamp open a date or location timeline?

Yes. In PRO, long-press the time area to open the daily timeline for that date, or long-press the mini map to open the location-based timeline for that place. In FREE, long-pressing the mini map opens the location in the Maps app instead. A brief tap only hides TimeMapStamp, and these long-press actions provide subtle haptic feedback.

How do the TimeMapStamp switches work together?

TimeMapStamp is the main switch. Sunrise & Sunset and Moon Phase are independent options underneath it. If the main switch is off, neither optional section runs or appears; if it is on, either option can be used alone or both can be enabled together.

What are the default TimeMapStamp settings on a new installation?

TimeMapStamp is on, Sunrise & Sunset is on, and Moon Phase is off by default. Changing these switches later keeps your chosen settings.

What information is required for Sunrise & Sunset?

The media must contain a usable capture date and valid GPS coordinates. If either is missing, the sunlight section is simply omitted while the rest of the available TimeMapStamp information can still appear.

What information is required for Moon Phase?

A usable capture date is enough. GPS is not required for the moon phase row, so it can appear even when the photo has no location metadata.

Does Sunrise & Sunset request my current location?

No. It uses the capture time and GPS coordinates already stored in the media metadata. It does not need to use the phone's current location to calculate the photographed moment.

What does the horizontal sunlight bar represent?

It is a compact 24-hour timeline for the photographed date and place. Sunrise, sunset, and the capture-time marker are positioned according to where they fall within that day.

What does the vertical marker on the sunlight bar mean?

It marks the photo or video's recorded capture time. This makes it easy to see whether the media was created before sunrise, during the day, near sunset, or at night.

What do Civil, Nautical, and Astronomical Twilight mean?

They are progressively darker stages between daylight and full night. Civil twilight is the brightest, nautical twilight is darker, and astronomical twilight is the final faint-light stage before night.

What are Golden Hour and Blue Hour?

Golden Hour is the low-sun period that often produces warm, soft light. Blue Hour is the cooler, dimmer period around twilight. The displayed phase describes the photographed time and location, not a filter applied to the image.

What does Sun Altitude mean?

Sun Altitude is the sun's angle above or below the horizon at the capture time. A positive value places it above the horizon; a negative value places it below the horizon.

What do N, NE, E, SE, S, SW, W, and NW mean in TimeMapStamp?

They are compass directions for the sun's azimuth at the photographed moment. They describe where the sun was positioned around the horizon, not the direction the camera was pointing.

What does Daylight Duration mean?

It is the length of time between sunrise and sunset for the photo's date and location. It naturally changes with season and latitude.

Which time zone is used for the displayed sunlight times?

TorchPhoto uses the photographed location's time zone when it can be determined from the existing metadata lookup. If that is unavailable, it falls back to the device's current time zone.

What happens in a place with Midnight Sun or Polar Night?

If there is no normal sunrise or sunset on that date, TorchPhoto does not invent marker times. It identifies the polar-day or polar-night state and shows an appropriate daylight duration.

What does the Moon Phase row show?

It shows the moon-phase name, a matching moon icon, approximate illumination, and moon age for the recorded capture moment.

Why is TimeMapStamp or one of its astronomy rows missing?

Check the relevant setting and the media metadata. A missing or invalid capture date prevents time-based information, while missing GPS prevents Sunrise & Sunset and map-based details. Moon Phase can still work from a valid date alone.

Does viewing TimeMapStamp change the photo metadata?

No. TimeMapStamp reads available information for display and does not rewrite the capture date, GPS coordinates, or original media file.

Which protocols support direct remote video streaming?

SFTP, SMB, and compatible WebDAV servers can use range-based remote streaming. TorchPhoto requests only the portions needed by the player and can fall back to a temporary download when streaming is not usable.

How does video playback work over FTP?

FTP video playback uses a download-based path rather than the direct remote streaming session used by SFTP, SMB, and compatible WebDAV connections. A large FTP video can therefore take longer before playback begins.

Is a video over 3GB automatically too large to play?

No. File size alone is not a fixed playback limit. Large-file success also depends on the protocol, server range-read performance, network stability, available device storage for fallback, and whether the media format can be played by the device.

Why can seeking far ahead in a large remote video take time?

Moving the playhead far away requires new byte ranges from a different part of the file. A slow server, high latency, weak Wi-Fi, or media whose indexing information is difficult to access can delay playback at the new position.

What happens if remote video streaming stalls?

TorchPhoto can rebuild the streaming session around the current playback position. If the remote stream still cannot recover, it falls back to temporary-download playback instead of waiting indefinitely.

Why does a WebDAV video download instead of stream?

Direct WebDAV streaming requires correct HTTP byte-range support. If the server does not return partial content reliably, TorchPhoto uses the safer download fallback.

Does streaming remove the need for free device storage?

Not completely. Streaming uses temporary buffers, and a failed or unsupported stream may switch to a temporary full-file download. Very large videos therefore still benefit from adequate free space.

Can a supported file extension still fail to play?

Yes. A file extension is only the container name. The video or audio codec inside it must also be compatible with the device, and the file itself must not be damaged or incomplete.

Does closing the video player stop remote requests?

Yes. Closing or changing the video cancels the old streaming, monitoring, and download work so it is not applied to a different media item.

Why does sharing or saving a streaming video take longer than watching it?

Playback can request only the ranges it needs, but saving or sharing normally requires a complete temporary copy of the original video. The transfer time therefore depends on the full file size.

Is a video thumbnail the same as video streaming?

No. A video thumbnail is one small preview frame. Streaming supplies media data continuously for playback, so a generated thumbnail does not guarantee that the current server and network can stream the full video smoothly.

How does photo and video pairing recognize a pair?

When pairing is enabled, an image and video in the same folder with the same base filename can be treated as one related pair. The video is then opened from the image's pairing viewer instead of appearing as an unrelated item.

Why did a video disappear after I enabled pairing?

If it has the same base filename as an image in the same folder, TorchPhoto may be intentionally treating it as the image's paired video. Open the image and use its pairing control to access the video.

Can I create a new destination folder while uploading?

Yes. The upload folder picker can create a folder when the connected server, account permissions, and selected protocol allow it.

Can an upload browse outside the server's registered root folder?

No. Upload destinations are kept within the root path registered for that server. This prevents an accidental folder selection from escaping the intended browsing area.

Can thumbnails be generated automatically after upload?

Yes. Enable the upload option to create thumbnails for successfully uploaded media and refresh the related directory afterward.

Is there a fast way to select recent photos for upload?

Yes. Long-press the upload button in the server list to choose media from Today, Yesterday, This Week, This Month, or a custom date range.

Does a custom upload date range include the final day?

Yes. The selected end date is included in the custom range.

What can I learn from the upload log?

The log helps confirm which items completed and which failed. If an upload is missing, check the log before repeating the entire selection.

Can I upload with Apple Shortcuts?

Yes. PRO users can use TorchPhoto's Shortcuts actions with a registered server and destination folder, subject to Photos access, server availability, and iOS background limits.

Should I keep TorchPhoto open during a very large upload or backup?

For the most reliable result, keep the app in the foreground until a long transfer finishes. iOS can limit background execution, especially during large uploads, full-file video fallbacks, and thumbnail backup or restore.

Does a browser need TorchPhoto installed to view Local Wi-Fi Gallery Share?

No. A device on the same reachable local network can open the provided gallery address in a normal web browser.

Why can another device not open my Local Wi-Fi Gallery?

Confirm that both devices are on the same network, Local Network access is allowed, the displayed address and port are correct, and the router is not isolating wireless clients from one another.

Does Local Wi-Fi Gallery Share upload my library to a cloud service?

No. It serves the gallery from the device over the local network for the active sharing session.

Should I keep the gallery sharing screen active?

Yes. Keep TorchPhoto running while others browse the local gallery. If iOS suspends the app, the temporary local web session can become unavailable.

Why would I change the Local Wi-Fi Gallery port?

Change it if the default port is already in use or blocked on the local network. After changing it, share the newly displayed URL or QR code because the old address will no longer match.

Does TorchPhoto modify originals when browsing, creating thumbnails, or showing metadata?

No. These are read-only viewing operations. Original server files change only when you explicitly use an action such as upload, delete, or another available file operation.

What should I check if thumbnails work but originals do not open?

Cached thumbnails can work offline even when the server cannot deliver the original. Check the current connection, credentials, file permissions, remote path, Wi-Fi or cellular original-loading setting, and available storage for large temporary downloads.

Why can a file appear in list view but not open in the preview?

The server may identify it as media by name or extension even though its internal format is unsupported, damaged, or incomplete. Try downloading the file and checking whether the device can open it locally.

Why do dates or locations sometimes differ from what I expect?

TorchPhoto displays the metadata available in the file. Exporting, editing, messaging, or copying media can remove or replace capture dates, GPS data, and time-zone clues, so the shown result may reflect the exported file rather than the original camera record.

What should I do before deleting remote media in TorchPhoto?

Confirm the selected files, server, and folder carefully. A remote delete affects the server copy and may not be recoverable through TorchPhoto; recovery depends on the server's own recycle-bin or backup policy.

What are the main default settings on a new installation?

Media-Only Mode, Instant Thumbnail, Wi-Fi-only original auto-load, TimeMapStamp, and Sunrise & Sunset start enabled. Instant Thumbnail starts at Low quality. Preview quality options and Moon Phase start disabled. Existing user choices are not replaced by new-install defaults.

How can I see the default popup guides again?

Open TorchPhoto Settings, scroll to the bottom, and tap Reset Tips. This clears saved “Don’t show again” choices for supported feature tips, including the Timeline Viewer guide, so each related tip can appear again the next time you enter its screen or use its action.

Reset Tips does not remove registered servers, photos, captions, thumbnail caches, subscriptions, or your other app settings.

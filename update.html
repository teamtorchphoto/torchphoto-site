Update

TorchPhoto update notes are organized by version below.

v3.3

1. Improved the design of the Add Server page

2. Added support for saving paired videos as Live Photos

3. Improved delays that occurred in selection mode

4. Fixed uploads so edited photos and videos are uploaded instead of the originals

5. Added widget image refresh when entering the app from a widget

6. Changed the toast popup style, added time display after the date, and removed duplicate addresses

7. Added support for changing the column layout with a pinch-out gesture

8. Other bug fixes and usability improvements

v3.2

1. Added frame saving for paired Live Photos

2. UI improvements and other bug fixes

v3.1

Added a PRO-exclusive thumbnail cache backup and restore feature

(Backed-up thumbnails can be restored on other devices with TorchPhoto installed, and used immediately without regenerating thumbnails)

v3.0

Improved usability and fixed other bugs

(Fixed an issue where an upload count limit error was incorrectly applied to PRO subscribers and lifetime users)

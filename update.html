Support

Update

TorchPhoto update notes are organized by version below.

v12.4

1. Based on received crash reports, we fixed a crash affecting the SMB protocol and improved stability.

2. Added diagnostics to TorchPhoto. When a critical error is detected, diagnostics become available in Settings. Diagnostic information does not include personal data.

3. Fixed other bugs and improved parts of the user interface.

v12.3

1. Fixed an issue where SFTP videos fell back to full downloads, improving streaming playback.

2. Reviewed SFTP, SMB, and WebDAV functionality and improved stability for each protocol.

3. Improved the stability of uploads through Shortcuts.

4. Fixed other bugs and refined parts of the user interface.

v12.2

Fixed other bugs and improved the user interface.

v12.1

1. You can now add or edit captions for individual items in Metadata. Saved captions appear as text at the top center of the viewer.

2. The Full Thumbnail Generation screen now shows progress and estimated time remaining, followed by the total elapsed time when complete.

3. Added the ability to rotate selected thumbnail images left or right in Selection Mode.

4. Improved overall usability and fixed other bugs.

v12.0

1. Added support for additional image and video file extensions beyond the previously supported formats.

(Previously supported formats: jpg, jpeg, png, gif, bmp, tif, tiff, heic, heif, webp, avif, raw, dng, mp4, mov, m4v, 3gp, 3g2, mpg, mpeg, m2v, webm)


Newly added formats

Images: jpe, jfif, apng, dib, hif, jxl, jp2, j2k, jpf, jpx, psd, psb, exr, tga, targa, hdr, pic, ico, cur, svg, dds, ppm, pgm, pbm, pnm, crw, srf, sr2, rwl, 3fr, mef, mos, kdc, dcr, erf, x3f, iiq

Videos: mkv, avi, qt, ts, mts, m2ts, m1v, mxf, wmv, asf, flv, f4v, vob, ogv, rm, rmvb, divx, xvid, mod, tod, dv, mjpeg, mjpg, y4m, hevc, h265, h264, avc


2. Improved thumbnail display speed in the server list.


3. Other bugs have been fixed.

1. Improved the Favorites experience and added slideshows for favorite items.

2. Fixed additional slideshow issues and improved reliability.

3. Added Live Photo and video badge icons for paired items when Video Pairing is enabled.

v11.8

1. Added Offline Thumbnail Enhancement. When your server is powered off or the internet is unavailable, TorchPhoto can enhance lower-quality cached thumbnails directly on your device, making Offline Mode more useful for browsing prepared memories anywhere.

2. Upgraded slideshows. Fill Screen now gently pans across cropped areas in a random direction, first-photo original loading is more reliable, and large-library playback has been improved. Free users can try up to 10 photos per server, while PRO plays without a photo limit.

3. HDR photos are now identified with a subtle “HDR” label in the upper-right corner after the original finishes loading.

v11.7

1. Long-press the Photo Selection button to open the Files app. You can select and upload supported photos and videos from external storage and removable drives.

2. Slideshow features have been added. Each server remembers settings such as the playback interval, background music, and starting volume, and you can select multiple songs from the Music app for sequential, repeating playback.

3. Overall usability and UI have been improved, including landscape layouts for image and video previews, upload menus and date-range selection, and server management menus.

Update

TorchPhoto update notes are organized by version below.

v6.3

Fixed an issue where thumbnails were not generated during uploads and Shortcuts automatic backups

v6.2

1. Improved the reliability of offline mode detection.

2. Improved the speed and stability of file downloads and selected-item sharing preparation.

3. Original filenames are now preserved when sharing files.

4. The share sheet now opens only after all selected items are fully prepared.

5. Added a confirmation dialog before sharing selected items and updated localized text.

6. Improved the top-right menu so it is properly disabled during downloads.

7. Fixed duplicate or incorrect download progress indicators during video playback and preview.

8. Refined the metadata display UI in the image and video viewer.

9. Added date and time display to slideshows using regional formats and improved the design.

10. Fixed an issue where PRO-only upload and widget features could be used in the FREE version, and improved access restrictions and guidance.

11. Improved the usability and design of the QR code server setup screen.

12. Improved edge-swipe navigation in the initial folder, Upload, and Upload Logs screens.

13. Fixed issues related to folder navigation and thumbnail display.

14. Updated localized text and improved general UI presentation across multiple languages.

15. Improved overall performance and stability.

v6.1

1. The PRO plan page has been improved to make it easier to view and use

2. A feedback form has been added to the Support page. After reviewing your feedback and identifying the issue, we will reply with the planned improvements and actions taken

3. The automatic backup feature using Shortcuts has been improved for greater stability (PRO)

v6.0

1. Fixed a compatibility issue that prevented folders from opening properly on some FTP servers

2. The TorchPhoto Shortcut for automatic uploads has been updated to version 2 and now supports uploading photos, Live Photos, and videos.

(For more details, see the Shortcuts menu in Settings.)
